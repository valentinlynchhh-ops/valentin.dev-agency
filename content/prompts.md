# Prompts listos (ChatGPT, Claude, generadores de imagen y video)

Copiá, reemplazá lo que está entre `[corchetes]` y pegá. **Adjuntá siempre** `design.md` y `references/branding-reference.webp` cuando la herramienta lo permita. Revisá todo con el checklist de `design.md` §16 antes de publicar.

## Datos fijos de la marca (para pegar en cualquier prompt)
```
Marca: valentin.dev (siempre en minúsculas). Desarrollador creativo independiente, Argentina.
Color: negro #0A0A0A dominante (~60%), amarillo cálido #FFE600 (~30%), blanco roto #F5F5F0 (~10%). Colores planos y mates, sin degradados ni brillos.
Tipografía: grotesca bold tipo Neue Montreal, compacta, interlineado ajustado.
Composición: editorial, asimétrica, mucho aire, una sola idea. Un solo motivo gráfico: escalera de píxeles cuadrados O flecha noreste.
Voz: español rioplatense, primera persona, frases cortas.
```

## 1) Post de Instagram (imagen estática 1080×1350)
```
Create ONE finished Instagram post for valentin.dev, an independent web designer and developer in Argentina.
Canvas 1080x1350 (4:5). Use the attached DESIGN.md and branding board as identity reference, not as the layout to copy.
Post type: [statement / proof / offer / process / editorial].
Exact headline (Spanish, do not change or add text): "[titular]".
Optional second line: "[subtítulo]".
Style: refined neo-brutalism, Swiss editorial typography, black #0A0A0A background, a single warm yellow #FFE600 highlight block behind the key word, paper white #F5F5F0 text. ONE graphic motif only: [pixel-step block / northeast arrow]. Lots of negative space.
No gradients, glow, 3D, mockups, stock photos, extra text, watermarks, or emojis. Check spelling.
```

## 2) Carrusel (5–7 slides, cada una 1080×1350)
```
Actúa como director de arte. Diseñá un carrusel de [N] slides para Instagram de valentin.dev. Tema: "[tema]".
Cada slide es una imagen separada de 1080x1350. Mismo grid, misma tipografía, mismo lugar para el wordmark y el número de slide.
Estructura: 1 gancho → 2 contexto → 3 problema → 4 explicación → 5 ejemplo → 6 conclusión → 7 acción única.
Textos exactos por slide: [pegá acá el texto de cada slide].
Fondos: negro dominante, 1 o 2 slides amarillas, 1 blanca para descansar. Una palabra o línea por slide en bloque amarillo con texto negro. Sin ilustraciones decorativas. Si uso capturas de trabajos reales, ocupan buena parte del slide.
```

## 3) Guion de video (TikTok / Reel de 20–35 s)
```
Escribí un guion de TikTok/Reel de 20 a 35 segundos para valentin.dev (diseño y programo webs para negocios de Argentina).
Tema: "[tema]". Gancho elegido (primeros 3 s): "[gancho]".
Formato de salida: tabla con columnas  Tiempo | Qué se ve | Qué digo | Texto en pantalla.
Reglas: español rioplatense, primera persona, frases cortas. Se entiende sin sonido. Una sola acción al final.
Prohibido inventar clientes, cifras, resultados o testimonios. Si hace falta un dato que no te di, dejá [DATO] y preguntame.
Si mencionás precios usá {{precio:landing}}, {{precio:web}} o {{precio:sistema}} y no el número.
```

## 4) Imagen o video con IA (solo fondos, texturas y piezas sin texto)
```
Create a single photographic asset, NOT a complete design, and NO TEXT.
Subject: [concrete architecture / desk with a real laptop screen showing a website / concrete wall / black fabric].
Lighting: natural directional side light, physically plausible shadows. Treatment: neutral monochrome, deep charcoal blacks with retained detail, paper-like highlights, restrained real grain, sharp focal point.
Leave the [upper-left / lower third] area quiet for typography to be added later. No logos, no invented people, no fake screens.
```
> Para video: `Vertical 9:16, 5 seconds, slow push-in, same treatment, no text, no people, no logos.` El texto y el wordmark se agregan después con una herramienta de edición, no con la IA.

## 5) Caption para Instagram o TikTok
```
Escribí el texto de pie para un post de valentin.dev. Tema: "[tema]". Máximo 4 líneas.
Primera línea = gancho que se entienda sola. Sin emojis decorativos. Español rioplatense, primera persona.
Una sola acción al final (ej: "Contame tu proyecto por mensaje"). 3 a 5 hashtags relevantes y específicos (no genéricos).
No inventes datos, clientes ni resultados.
```

## 6) Auditoría antes de publicar
```
Actuá como director de arte de valentin.dev. Te adjunto la pieza y DESIGN.md. Revisala contra la rúbrica de 100 puntos y la tabla "Problema detectable → Corrección".
Devolveme: puntaje, fallas críticas, 3 correcciones concretas y qué no pudiste verificar. No me felicites: buscá lo que está flojo.
```
